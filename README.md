# Sistema de Funcionários em Java

Projeto desenvolvido em **Java** com o objetivo de praticar conceitos fundamentais de **Programação Orientada a Objetos (POO)**.

O sistema representa funcionários de uma empresa, permitindo cadastrar suas informações, calcular o salário anual e aplicar aumentos salariais de diferentes formas.

## 🎯 Objetivo

Praticar conceitos de POO utilizando uma classe `Funcionario`, trabalhando principalmente com:

- Encapsulamento
- Atributos privados
- Getters e Setters
- Métodos com retorno
- Métodos com parâmetros
- Sobrecarga de métodos
- Condicionais
- Manipulação de valores numéricos
