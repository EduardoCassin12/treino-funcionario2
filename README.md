# 👨‍💼 Sistema de Funcionários

Sistema desenvolvido em **Java** para praticar conceitos de **Programação Orientada a Objetos (POO)**, gerenciamento de objetos e utilização de `ArrayList`.

## 📋 Sobre o projeto

O projeto simula um sistema simples de gerenciamento de funcionários de uma empresa.

A aplicação permite cadastrar funcionários, consultar informações, alterar salários, remover funcionários e calcular o valor total da folha salarial.

## 🚀 Funcionalidades

- Cadastro de funcionários
- Listagem de funcionários
- Busca de funcionário por ID
- Remoção de funcionário por ID
- Exibição das informações dos funcionários
- Aumento salarial de 10%
- Aumento salarial utilizando percentual personalizado
- Cálculo do valor total da folha salarial
- Gerenciamento de funcionários utilizando `ArrayList`

## 📁 Estrutura do projeto

    src/
    ├── Funcionario.java
    ├── Empresa.java
    └── Main.java

### `Funcionario`

Responsável por representar cada funcionário e suas informações:

- ID
- Nome
- Cargo
- Salário

Também possui métodos relacionados ao aumento salarial e à exibição das informações.

### `Empresa`

Responsável por gerenciar a lista de funcionários.

Entre suas responsabilidades estão:

- Adicionar funcionários
- Buscar funcionários
- Remover funcionários
- Listar funcionários
- Calcular a folha salarial

### `Main`

Responsável pela execução e demonstração das funcionalidades do sistema.

## ▶️ Como executar

1. Clone o repositório:

       git clone <URL_DO_REPOSITORIO>

2. Abra o projeto em sua IDE.

3. Execute a classe `Main.java`.
